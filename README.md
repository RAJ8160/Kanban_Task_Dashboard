# Todo Task Manager

## 📌 Description

Todo Task Manager is a simple task management application built using React.js. It helps users manage their daily tasks by allowing them to add, edit, delete, and search tasks.

Users can also set task priorities, update task statuses, and assign due dates. The application uses LocalStorage to save tasks, so they remain available even after refreshing the browser.

## ✨ Features

- Add new tasks.
- Edit existing tasks.
- Delete tasks.
- Search tasks.
- Set task priority (Low, Medium, High).
- Set task status (ToDo, InProgress, Completed).
- Add due dates to tasks.
- Form validation using React Hook Form.
- Store tasks in LocalStorage.

## 🛠️ Technologies Used

- **Frontend:** React.js
- **Language:** JavaScript
- **Styling:** Tailwind CSS
- **Form Handling:** React Hook Form
- **Storage:** LocalStorage
